## Existing schema and proposed additions

Existing definitions can represent brand, product type, base, purpose, package weight, layer text, 10 mm consumption, water requirement, application area/method, substrates, color, temperature, pot life, compressive strength, adhesion, frost resistance, standard, mortar grade and shelf life. Discovery did not create or modify definitions or templates.

Potential new definitions for a later schema review:

| Code | Type | Reason |
|---|---|---|
| `consumption` | text | Generic kg/m²/mm values are not always the same semantic as `consumption_10mm`. |
| `flexural_strength` | number, МПа | Published by several exact products. |
| `walkability` | text | Time to walk is distinct from pot life and drying. |
| `flooring_installation_time` | text | Covering-installation window is distinct from walkability. |
| `minimum_layer`, `maximum_layer` | number, мм | Optional numeric filtering; otherwise preserve the range in `layer_thickness`. |
| `operating_temperature` | text | Product service temperature differs from application temperature. |

No definition or template should be created until a separate core-batch decision.
